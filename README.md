# Kids Mode Fun

Kostenloses Lernspiel für Kinder. Ohne Werbung, ohne In-App-Käufe, ohne Tracker.

**Spielen:** [https://kids-mode-fun.grok.me](https://kids-mode-fun.grok.me)

Eltern geben dem Kind das Handy — die App bleibt ruhig, klar und pädagogisch.

## Was drin ist

- **Zahlen** — Zählen und Zehnerrahmen
- **Formen** — Kreis, Viereck, Stern und mehr, mit steigendem Level
- **Farben** — Benennen; Muster helfen bei Farbenblindheit
- **Memory** — Paare merken
- **Hasenfang** — Tippen und reagieren

## Sprachen & Sehen

- Deutsch, English, Français, Italiano
- Farbenblind-Modi: Rot / Grün / Blau, jeweils leicht und vollständig
- Hoher Kontrast
- Vorlesen (Web Speech) und leise Töne, abschaltbar hinter einer Eltern-Sperre

Fortschritt bleibt nur auf dem Gerät (localStorage). Nichts geht in die Cloud.

## Selbst starten

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
npm run preview
```

Node 22+, kein Konto, keine Datenbank.

## Lizenz

MIT — nimm es, fork es, gib es weiter. Kinder sollen spielen dürfen, ohne Paywall.

# Kids Mode Fun (English)

A free learning app for children. No ads, no in-app purchases, no trackers.

**Play it live:** [https://kids-mode-fun.grok.me](https://kids-mode-fun.grok.me)

Five calm games (numbers, shapes, colors, memory, bunny catch), four languages, and color-vision modes including high contrast. Progress stays on the device.

MIT licensed. Built with React, Vite, Tailwind, and Zustand.
